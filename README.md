# -Governance-Embedded-Agent-Architecture-GEAA-
Governance-Embedded Agent Architecture (GEAA): task-scoped authority mediation for LLM agents. Replication code and data for a deterministic AgentDojo v1.2.2 replay (949 task–attack pairs, 13 grant/exception policies) and a live Claude agent evaluation, with frozen risk tiers, approver configs, and results.
